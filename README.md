# Full-Stack Portfolio: Industrial IT & Automation
Welcome to my professional portfolio. This project showcases a comprehensive full-stack environment designed for **Industrial IoT (IIoT)** monitoring and system automation. It integrates modern web technologies with industrial protocols and backend data processing.

## 🛠️ Technical Stack
- **Frontend:** HTML5, CSS3 (Modern Dark Theme), Vanilla JavaScript
- **Backend:** Node.js, Express
- **Industrial Logic:** Python (Modbus TCP communication, Data Logging)
- **Database:** SQL Server (Structured historical data storage)
- **Automation:** PowerShell scripting for system-level tasks

I am an Industrial IT enthusiast focusing on the intersection of automation, software development, and cybersecurity. My goal is to build secure, scalable, and efficient systems for the future of Industry 4.0.
